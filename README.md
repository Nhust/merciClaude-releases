# MerciClaude

Versions de MerciClaude à télécharger (Mac, Apple Silicon). Voir les [releases](https://github.com/Nhust/merciClaude-releases/releases).

Installation : dézippe, glisse **MerciClaude.app** dans Applications, puis `xattr -dr com.apple.quarantine /Applications/MerciClaude.app`. Les versions suivantes se mettent à jour depuis l’app.
